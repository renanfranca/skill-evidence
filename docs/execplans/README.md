# Execution Plans

This directory is the canonical home for living Execution Plans (ExecPlans) in
this repository.

Name plans `<YYYY-MM-DD>_<TYPE>_<short-kebab-title>-exec-plan.md`, where `TYPE`
is a concise uppercase category such as `FEATURE`, `FIX`, `REFACTOR`, `DOCS`, or
`TEST`.

Every plan must be self-contained and keep these sections current: Purpose / Big
Picture, Scope, Definitions, Existing Context, Desired End State, Milestones,
Progress, Decisions, Risks and Mitigations, Validation Strategy, Documentation
Impact, Rollout and Recovery, and Lessons Learned.
